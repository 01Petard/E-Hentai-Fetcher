# E-Hentai Fetcher

一个运行在本机的第三方 E-Hentai 图库查询与浏览工具。

项目基于 **Vue 3 + Vite + Node.js** 构建，前端页面与本地请求代理统一运行在 `127.0.0.1:8765`。用户输入搜索条件或打开快捷链接后，由本地代理请求目标站点完整 HTML，前端负责解析并展示搜索结果、标签、分页、种子等信息。

> 本项目依赖 E-Hentai 当前页面结构与可用性。如果目标站点调整 HTML 结构，部分解析逻辑可能需要同步更新。

---

## 功能概览

### 1. 搜索与筛选

- **基础搜索**
  - 支持标题、关键词、组合标签等 E-Hentai 原始搜索语法。
  - 保留引号、分号、美元符号等特殊字符，并正确编码到 `f_search`。

- **高级筛选**
  - 只显示已删除图库。
  - 只显示有种子的图库。
  - 按页数范围筛选。
  - 按最低评分筛选。
  - 可控制语言、上传者、标签三个自定义过滤器。

- **搜索标签联想**
  - 根据本地缓存的标签数据库匹配中英文候选词。
  - 匹配文本高亮显示。
  - 支持上下方向键选择、回车填入和鼠标点击。
  - 最终写入搜索框的是 E-Hentai 使用的英文标签。

- **快捷链接**
  - 可保存自定义名称与完整 `https://e-hentai.org/` 地址。
  - 支持搜索结果页和上传者页面等地址。
  - 点击后直接通过本地代理请求并解析。
  - 配置保存在当前浏览器的 `localStorage`。

### 2. 搜索结果与浏览体验

- **多种结果视图**
  - 缩略图网格。
  - 带标签信息的扩展列表。
  - 紧凑的最小化列表。
  - 最小化列表支持悬停标题或标签区域时预览封面。

- **会话内恢复**
  - 首次打开主页时请求不带查询参数的 `https://e-hentai.org/`。
  - 同一标签页内跳转或刷新后，恢复搜索内容、筛选条件、展示模式和上次浏览的结果地址，并重新请求结果。
  - 查询状态保存在 `sessionStorage`，关闭标签页后清除。

- **分页导航**
  - 支持首页、上一页、下一页、末页。
  - 翻页链接直接使用目标站点响应 HTML 中的真实分页地址。

- **浏览进度定位**
  - 在结果上方显示当前页面大致覆盖的百分比区间。
  - 例如：`[20% - 30%]`。
  - 区间根据已知页序、当前页条目数和结果总数估算。
  - 当通过无法确定页序的游标链接直接进入时，不展示猜测结果。
  - 由于目标站点返回的总数可能为估算值，该进度仅用于快速定位浏览位置。

- **相对时间**
  - 较新的内容显示为“几分钟前”“几小时前”“几天前”。
  - 较早内容显示日期。
  - 悬停仍可查看完整时间。
  - 可在配置中心关闭。

### 3. 标签增强

- **画廊标签汉化**
  - 根据命名空间和原始标签名匹配 EhTagTranslation 社区数据库。
  - 例如：`f:race queen`。
  - 命中后显示中文标签。
  - 悬停可查看英文原文。
  - 未命中时保留原始标签。

- **标签详情**
  - 点击可识别标签后打开悬浮详情窗口。
  - 可查看：
    - 中文名称。
    - 英文原名。
    - 标签介绍。
    - 数据库提供的外部链接。
  - 没有介绍时显示对应提示。

- **标签数据库缓存与更新**
  - 服务端缓存标签数据库 6 小时。
  - 浏览器使用 IndexedDB 做持久缓存。
  - 首次加载标签数据库需要联网。
  - 可配置自动检查更新间隔。
  - 支持手动立即检查更新。
  - 更新失败时继续使用已有缓存数据。

### 4. 画廊辅助功能

- **站内种子列表**
  - 点击搜索结果中的“种子”后，在当前页面弹窗显示该图库可解析的种子列表。
  - 展示大小、做种数、连接数等信息。
  - 支持直接下载选中的 `.torrent` 文件。

- **响应调试页**
  - 提供独立 `/debug` 页面。
  - 可填写完整请求地址。
  - 可手动输入 Cookie。
  - 可选择是否请求 Extended 布局。
  - 可查看原始响应内容和解析结果。
  - 手动 Cookie 留空时使用本地已保存配置。

### 5. 配置中心

配置中心用于管理本地运行所需配置和浏览体验开关。

支持：

- 配置 Cookie 请求头。
- 查看 Cookie 是否已配置，但不会在页面中回显已保存内容。
- 增删快捷链接。
- 开关标签汉化。
- 开关标签详情。
- 开关搜索标签联想。
- 开关相对时间。
- 开关标签数据库自动更新。
- 设置自动检查间隔。
- 查看标签数据库版本与上次检查时间。
- 手动触发标签数据库更新检查。

浏览体验相关设置保存在当前浏览器中。

## 本地运行

### 环境要求

- Node.js `^20.19.0` 或 `>=22.12.0`
- npm

### 安装依赖

```bash
npm ci
```

### 启动开发环境

```bash
npm run dev
```

启动后访问：

- 主页：<http://127.0.0.1:8765/>
- 调试页：<http://127.0.0.1:8765/debug>

开发时只需要启动当前 Vite 服务，不需要额外启动 Python 服务。

### 生产构建

```bash
npm run build
npm run start
```

构建后的服务仍运行在：

```text
http://127.0.0.1:8765/
```

端口固定为 `8765`。

## 首次配置

1. 打开主页右上角的“配置”。
2. 在配置中心填写 **Cookie 请求头的值** 并保存。
3. Cookie 会写入项目根目录的 `.env.local`，由本机 Node 请求代理读取。
4. `.env.local` 已加入 `.gitignore`，不要将真实 Cookie 写入源码或提交到版本库。
5. 如有需要，可在配置中心新增快捷链接。
6. 快捷链接仅接受 `https://e-hentai.org/` 下的完整地址。
7. “浏览体验”中的设置修改后会立即生效。
8. 标签数据库首次加载后会缓存在浏览器中；开启自动更新后，会在页面打开期间按照设置的时间间隔检查更新。

请求目标站点时，本地代理会附带 Cookie、浏览器 User-Agent 等请求头。

目标站点仍可能返回 `403` 或其他错误。发生异常时，可以在主页查看原始 HTML，或打开 `/debug` 页面进一步排查。

## 搜索请求规则

普通搜索只发送必填参数 `f_search`。

只有开启高级筛选后，才会附加：

```text
advsearch=1
```

以及当前实际选择的筛选参数。未选择的筛选项不会发送。

| 参数 | 页面选项 | 发送规则 |
| --- | --- | --- |
| `f_search` | 搜索框 | 必填，按原始输入编码 |
| `f_sh` | 只显示已删除图库 | 选中时发送 `on` |
| `f_sto` | 只显示有种子的图库 | 选中时发送 `on` |
| `f_spf` / `f_spt` | 最少 / 最多页数 | 可分别填写 1–9999 的整数；同时填写时差值至少为 20，且最小值不超过最大值的 80% |
| `f_srdd` | 最低评分 | 选择 2–5 星时发送对应数字；“无限制”时省略 |
| `f_sfl` / `f_sfu` / `f_sft` | 禁用语言 / 上传者 / 标签自定义过滤器 | 选中时发送 `on` |

## 页面解析规则

搜索结果来自目标站点返回的完整 HTML。

当前主要依赖：

| 页面结构 | 用途 |
| --- | --- |
| `table.itg.glte` | 解析画廊条目 |
| `.searchtext p` | 获取搜索结果总数 |
| `.searchnav` | 获取分页地址 |

浏览进度根据以下信息估算：

- 已知当前页序。
- 当前页面条目数。
- 搜索结果总数。

如果当前访问方式无法可靠确定页序，则不会显示浏览进度区间。

## 数据存储与缓存

| 数据 | 存储位置 |
| --- | --- |
| Cookie | 项目根目录 `.env.local` |
| 快捷链接 | 浏览器 `localStorage` |
| 浏览体验配置 | 当前浏览器 |
| 标签数据库 | 服务端缓存 + 浏览器 IndexedDB |

Cookie 属于敏感信息，请勿提交到版本库、日志或其他公开位置。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `src/App.vue` | 搜索、结果视图、分页、配置与种子弹窗 |
| `src/search.js` | 搜索参数编码与校验 |
| `src/parseGallery.js` | 解析画廊 HTML |
| `src/parseTorrents.js` | 解析种子页面 HTML |
| `src/tagTranslations.js` | 标签翻译、浏览器缓存与刷新 |
| `server/api.js` | 本地请求代理、Cookie 配置、标签数据库和种子下载接口 |
| `debug.html` | 原始响应调试页 |
| `docs/` | 用于参考页面结构的响应示例 |

## 使用限制

- 本项目依赖目标站点的 HTML 页面结构，站点结构变化可能导致解析失效。
- 搜索结果总数可能由目标站点估算，因此浏览百分比区间只用于辅助定位。
- 标签翻译与标签详情依赖外部标签数据库，首次加载需要联网。
- 即使 Cookie 和请求头配置正确，目标站点仍可能返回 `403` 或其他访问错误。
- 本项目仅在本机运行，Cookie 等敏感配置不应提交到版本库。
